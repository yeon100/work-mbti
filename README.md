# EMO Task 업무 캐릭터 테스트

30개 질문으로 업무 캐릭터 12종 중 하나와 성향 지수를 알려 주는 모바일 웹 테스트입니다. 빌드 없이 HTML·CSS·JS만으로 동작합니다.

참여자는 시작 화면에서 팀과 이름을 적고, 결과가 나오면 팀·이름·캐릭터·응답이 진행자의 구글 시트로 한 줄씩 쌓입니다.

## 로컬에서 실행

```bash
python3 -m http.server 4317
```

브라우저에서 http://localhost:4317 을 엽니다.

## 진행자 설정

### 1. 결과를 받을 구글 시트 만들기

1. 구글 시트를 새로 만들고 확장 프로그램 → Apps Script를 엽니다.
2. `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. 배포 → 새 배포 → 유형 선택에서 웹 앱을 고릅니다.
   - 다음 사용자로 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자
4. 권한 승인 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
5. 그 주소를 브라우저에서 열어 `동작 중이에요` 메시지가 나오면 준비 완료입니다.

시트에는 `응답` 탭이 자동으로 생기고 아래 열이 채워집니다.

| 제출시각 | 팀 | 이름 | 캐릭터 | 일 처리 | 협업 | 에너지 | 응답 | runId | 성향 지수 |
|---|---|---|---|---|---|---|---|---|

같은 참여자가 결과 화면을 새로고침해도 한 번만 기록되고, 다시 하기로 새로 풀면 새 줄이 추가됩니다.

성향 지수는 일 처리·협업·에너지마다 고른 답을 100점 만점으로 환산한 값입니다. 예: `일 처리 설계 70 · 협업 몰입 60 · 에너지 안정 40`. 이미 쓰던 시트라면 `성향 지수` 열이 맨 뒤에 추가됩니다. Apps Script를 고친 뒤에는 배포 관리에서 새 버전으로 다시 배포해야 반영됩니다.

### 2. `config.js` 고치기

```js
const SUBMIT_URL = "https://script.google.com/macros/s/…/exec";
const TEAMS = ["기획팀", "개발팀", "디자인팀"]; // 비워 두면 팀을 직접 입력
```

`TEAMS`를 채우면 팀을 목록에서 고르게 되어 `기획팀`, `기획` 같은 표기 차이가 생기지 않습니다.

Apps Script 코드를 고친 뒤에는 배포 관리 → 수정 → 버전을 새 버전으로 바꿔 다시 배포해야 반영됩니다. 이 방법으로 다시 배포하면 `/exec` 주소는 그대로입니다.

## 휴대폰에서 열기 (GitHub Pages)

1. GitHub 저장소 → Settings → Pages
2. Source: Deploy from a branch, Branch: `main`, 폴더 `/ (root)` → Save
3. 1–2분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소가 생깁니다.

이 주소를 QR 코드로 만들어 워크샵 화면에 띄우면 됩니다. `git push`할 때마다 자동으로 다시 배포됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 진입점 |
| `config.js` | 진행자 설정 (수집 주소, 팀 목록) |
| `data.js` | 축, 문항, 캐릭터, 궁합 문구 |
| `app.js` | 화면 전환, 점수 계산, 결과 전송 |
| `style.css` | 스타일 |
| `img/` | 캐릭터 이미지 |
| `apps-script/Code.gs` | 구글 시트에 붙여 넣을 수집 스크립트 |
